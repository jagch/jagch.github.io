# Mi Portafolio

Portafolio web de un Fullstack Developer especializado en Backend, creado con React v18 y efectos visuales avanzados.

## Características

- ✨ Particles.js background interactivo
- 🎨 Diseño moderno con gradientes y animaciones
- 📱 Fully responsive
- ⚡ React v18 con Vite
- 🚀 Efectos visuales avanzados
- 📧 Formulario de contacto funcional

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Previsualización

```bash
npm run preview
```

## Estructura del Proyecto

```
src/
├── components/
│   ├── ParticlesBackground.jsx  # Background animado con partículas
│   ├── Hero.jsx                 # Sección principal con imagen
│   ├── About.jsx                # Sobre mí y habilidades
│   ├── Projects.jsx             # Proyectos destacados
│   └── Contact.jsx              # Formulario de contacto
├── App.jsx                      # Componente principal
└── App.css                      # Estilos globales
```

## Tecnologías

- React 18
- Vite
- tsparticles (nueva versión de particles.js)
- CSS3 con animaciones avanzadas

## Imagen de Perfil

Para agregar tu imagen de perfil:

1. Coloca tu imagen en `public/me.jpeg`
2. O modifica la ruta en `src/components/Hero.jsx` línea 8
